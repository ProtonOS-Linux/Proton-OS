# Proton OS 1.0 Core - Pre-installed Software

## Brave Browser (brave-origin)
Installed via official Debian repo method from brave.com/linux:
sudo apt install curl
sudo curl -fsSLo /usr/share/keyrings/brave-browser-archive-keyring.gpg \
  https://brave-browser-apt-release.s3.brave.com/brave-browser-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/brave-browser-release.sources \
  https://brave-browser-apt-release.s3.brave.com/brave-browser.sources
sudo apt update
sudo apt install brave-origin

## Firefox ESR
Included in Debian 13. Marked manual so it is never auto-removed
(used for the web apps):
sudo apt-mark manual firefox-esr

## Collabora Office (replaces LibreOffice and ONLYOFFICE)
"Collabora Office Desktop", installed as a system Flatpak from Flathub.
Opens .docx, .xlsx, .pptx, .odt and other office formats.
Flatpak languages set to *all*.

## earlyoom (memory safety switch)
sudo apt install earlyoom
Enabled by default on the live session and installed systems, with an
--avoid list so desktop processes are never chosen.

## Microsoft core fonts (optional)
Offered on the installer's "Third-party software" page (ticked by
default). Installed by the proton-msfonts timer/service about two
minutes after first boot, once online.

## Removed in 1.0 Core
LibreOffice, ONLYOFFICE, Variety, Docker.
