# Winboat Prerequisites (Podman + KVM method)
# https://github.com/TibixDev/winboat
# Verified against Winboat 0.9.2's built-in Pre-Requisites checker on Proton OS 1.0 Core
# (all prerequisites green with Podman)

Hardware minimums:
- At least 4 GB RAM
- At least 2 CPU cores

1. Enable virtualization (KVM) in BIOS/UEFI.

2. Podman and podman-compose (pre-installed on Proton OS):
   sudo apt install podman podman-compose fuse-overlayfs

3. Docker is NOT installed. The docker group and Docker config were
   removed in 1.0 Core.

4. FreeRDP 3.x from Debian (pre-installed, hidden from the Start menu):
   sudo apt install freerdp3-x11
   # Debian 13 Trixie: 3.15.0+dfsg-2.1+deb13u3

5. Winboat 0.9.2 (.deb from the GitHub releases page), pre-installed.

6. First run: Winboat's setup starts on Docker by default.
   Choose Podman as the container runtime.
